ADRIANTECH PORTFOLIO
====================

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted AdrianTech-Portfolio folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. Keep the images folder beside index.html. Do not move the image files out of it.

FILES
- index.html       Website content and structure
- style.css        Responsive navy-and-blue design
- script.js        Mobile navigation and active menu behaviour
- images/profile.jpg  Your first supplied photo (Home section)
- images/about.jpg    Your second supplied photo (About section)
- images/adriantech-banner.png  Optional generated brand banner (if included)
